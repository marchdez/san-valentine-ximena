# 💘 San Valentine – Ximena

Este repositorio contiene una página web interactiva creada con HTML, CSS y JavaScript
para hacer una pregunta muy importante este 14 de febrero.

La página muestra una pregunta directa:
**“¿Quieres ser mi San Valentine?”**
con dos opciones de respuesta (Sí / No), efectos visuales y animaciones.
